This folder holds generated outputs — nothing here is meant to be
hand-written. Running `python train.py --task N` writes:

- `task1_metrics.json`, `task2_metrics.json`, `task3_metrics.json`,
  `task4_metrics.json` — one per task, matching what each task's
  section of `train.py` computes.
- `plots/` — figures generated during training/evaluation (F1 curves,
  ablation bars, t-SNE, per-tag charts, retrieval bars).
- `retrieval_examples/` — Task 4's qualitative retrieval output.

Running `python evaluate.py` afterward reads whichever of the above
exist and writes `final_comparison.csv` — the cross-task table from
Section 8 of the report.

If you want the actual results committed as visible proof (rather than
regenerated by re-running), copy your real `*_metrics.json` files from
your Kaggle session's `/kaggle/working/` into this folder before pushing.
