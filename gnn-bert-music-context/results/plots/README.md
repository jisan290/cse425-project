This folder holds the generated `mtat_master.csv`, `dataset_meta.json`,
and `task2_graphs/` (the cached per-clip segment graphs). These are
regenerated by running `python train.py --task 2` — they are not
committed here since the graph files can be large; a small sample
(20+ .pt files, satisfying the assignment's minimum) can be committed
if the grader needs to inspect them without re-running the pipeline.
